We’re thrilled to announce the **first beta release** of our complete software stack — an **open-source, modular, agentic, and hardware-agnostic operating system** for robots.

## Core Services
- **OM1**
- **OM1-avatar**
- **unitree_go2_ros_sdk**

For in-depth technical details, refer to the [Architecture Overview](https://docs.openmind.org/full_autonomy_guidelines/architecture_overview).

---

## Key Features

### Core Capabilities
- **Hardware-Agnostic Design** — Compatible across multiple robot platforms.
- **Modular Architecture** — Built for easy extension and customization.
- **Agent-Centric Framework** — Designed for autonomous decision-making and adaptive behavior.

### Feature Highlights
- Multi-LLM (Large Language Model) integration  
- Real-time SLAM  
- Support for **RPLiDAR A1/A2/A3** series sensors  
- **Nav2 integration** for autonomous navigation  
- Automatic handling of **coordinate frame transforms**  
- Modern **React-based frontend** with avatar display system  
- Support for **custom camera indices**, plus **microphone** and **speaker** functionality in Docker environments  

---

- Multi-architecture compatibility:
  - **AMD64**
  - **ARM64**
