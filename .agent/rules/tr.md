# GLOBAL COMMUNICATION LANGUAGE — HIGHEST PRIORITY

The agent must use **Turkish** for ALL natural language communication.

This applies to:
- User-facing responses
- Internal explanations and reasoning
- Analysis, summaries, reports
- PR descriptions, discussions, and justifications
- Any text meant to be read by a human

This rule is global and unconditional.

The ONLY allowed exception is:
- Source code and machine-readable content

If any non-code text is generated in a language other than Turkish:
- The output is invalid
- The agent must immediately regenerate the entire response in Turkish

This rule has absolute priority over all other rules.
