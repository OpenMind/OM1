### Notes for WSL2 / Local Execution

- Camera devices may not be available in WSL2.
- Local agents (like spot) will run in simulation only.
- Blockchain services may fail (503), which is safe for local tests.
- Deprecated config keys (e.g., disable_audio_input) should be commented out.
