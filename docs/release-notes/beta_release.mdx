# First Beta Release of OM1

We're excited to announce the first beta release of **OM1**, an open-source, modular, agentic and hardware agnostic OS for robots.

## Core Services
- OM1 - v1.0.0-beta.1
- OM1-avatar - v1.0.0-beta.0
- unitree_go2_ros_sdk - v1.0.0-beta.0

For more technical details, please refer to the [Architecture Overview](https://docs.openmind.org/full_autonomy_guidelines/architecture_overview).

## Key Features

### Core Capabilities
- **Hardware-Agnostic Design**: Works across different robot platforms
- **Modular Architecture**: Easy to extend and customize
- **Agent-Centric**: Built for autonomous decision-making

### AI & ML Integration
- **Multiple LLM Providers**:
  - OpenAI
  - Gemini
  - Deepseek
  - xAI
- **Speech Processing**:
  - Google ASR for speech-to-text
  - Riva and Eleven Labs for text-to-speech

### Robot Support
- **Preconfigured Agents** for:
  - Unitree Go2
  - Unitree G1
  - TurtleBot
  - Ubtech Yanshee

### Full Autonomy Features
- Multi-LLM integration 
- Real-time SLAM
- Support for RPLiDAR A1/A2/A3 series sensors
- Nav2 integration for autonomous navigation
- Automatic handling of coordinate frame transforms
- Modern React-based frontend with avatar display system
- Support for custom camera indices and enables both microphone and speaker functionality in Docker

### Simulation
- Gazebo support for Unitree Go2

### System Support
- Multi-architecture support:
  - AMD64
  - ARM64
