## Summary

OM1 v1.0.0 marks the first production-ready release, delivering enterprise-grade autonomous robotics capabilities. This release introduces full Gazebo simulation support, complete autonomy for Unitree G1 humanoid robots, over-the-air updates, and significant improvements to the developer experience through hot reload and configuration versioning.

## Key Highlights
- Full Autonomy for Go2 and G1
- Local LLM integration
- ML stack migration to NVIDIA Thor
- Hot Reload
- OTA updates
- Gazebo integration for Go2 with OM1
- Pydantic-Based Configuration

For in depth understanding, checkout our documentation and release notes.
