The Developer Cookbook is a collection of practical, high-impact recipes designed to help you extend, customize, and build on top of the OpenMind platform.
If the Quickstart shows you how to use OM1, this Cookbook shows you how to build with it.

Here's what you can do with OM1
1. Build a new config file
2. Introduce a new mode
3. Configure a new input Plugin
### Beginner-Friendly Notes

Even if you are not a coder, you can follow these steps:

- **Build a new config file**: Copy an existing example (like `spot`) and give it a new name. No programming required.
- **Introduce a new mode**: Modes control how the agent behaves. You can rename or describe a mode in the config file.
- **Configure a new input Plugin**: You can pick from pre-built inputs like vision, audio, or web data. Just select it in the config file, no coding needed.

This guide helps you understand each part of OM1 so you can run and test agents safely.
